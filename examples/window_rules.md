Window rules pin app windows to a corner of a display, or keep windows clear
of a left margin. They depend on your screens, so there are none here. Add a
"## " section per rule, with :key: value lines; see docs/window_rules.md.

For example, a section headed with an app's name, such as Slack, and the
fields screen_w 1920, screen_h 1200, anchor topLeft, width_min 0.3,
width_max 0.5, height_min 0.5 and height_max 1, each written as a :key: value
line, pins Slack's windows to the top left of a 1920x1200 display.
